## 🌊 ¿Qué hace este sistema?

Crypto Analytics es una plataforma que:

- Recoge datos del mercado en tiempo real  
- Los transforma en indicadores comprensibles (RSI, EMA, MACD…)  
- Genera proyecciones basadas en patrones  
- Interpreta señales simples (BUY, SELL, NEUTRAL)  
- Y presenta todo esto de forma clara en una interfaz visual  

Todo esto ocurre como un flujo vivo:

**Datos → Lectura → Interpretación → Claridad** :contentReference[oaicite:0]{index=0}  

No entrega certezas.  
Entrega contexto.

## 🔍 ¿Qué ve el usuario?

Al entrar, el usuario observa:

### 1. El presente
- Precio actual  
- Volumen  
- Estado del mercado  

### 2. La lectura técnica
- Indicadores que revelan comportamiento oculto  
- Ritmos, tensiones, impulsos  

### 3. La proyección
- Una estimación hacia el futuro cercano  
- No como promesa, sino como posibilidad  

### 4. La señal
- Una síntesis simple:
  - BUY → posibilidad de subida  
  - SELL → posibilidad de caída  
  - NEUTRAL → equilibrio / espera  

Todo visible, todo trazable.  
Nada oculto. :contentReference[oaicite:1]{index=1}

## 🧠 ¿Qué aprende el usuario?

El sistema no se domina.  
Se escucha.

Para utilizarlo bien, el usuario necesita cultivar:

### 1. Lectura antes que acción
Aprender a observar sin reaccionar inmediato.

### 2. Comprensión de indicadores
No memorizar fórmulas, sino sentir qué representan:
- RSI → sobrecompra / sobreventa  
- MACD → cambio de impulso  
- EMA → tendencia  

### 3. Relación entre señal y contexto
Una señal sola no decide.  
Se interpreta junto al entorno.

### 4. Disciplina emocional
El sistema muestra datos.  
El usuario gestiona su reacción.
